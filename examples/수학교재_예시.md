# Ⅰ. 다항식

## 1. 다항식의 연산

두 다항식 $A$, $B$의 덧셈과 뺄셈은 **동류항**끼리 모아서 계산한다.

::: 정의 동류항
문자와 차수가 각각 같은 항을 **동류항**이라 한다.
예를 들어 $3x^2y$와 $-5x^2y$는 동류항이다.
:::

::: 공식 곱셈 공식
$$(a+b)^2 = a^2 + 2ab + b^2$$
$$(a+b)(a-b) = a^2 - b^2$$
$$(x+a)(x+b) = x^2 + (a+b)x + ab$$
:::

::: 예제 곱셈 공식의 활용
$x + y = 5$, $xy = 3$일 때, $x^2 + y^2$의 값을 구하시오.

[풀이]
$x^2 + y^2 = (x+y)^2 - 2xy$ 이므로
$$x^2 + y^2 = 5^2 - 2 \times 3 = 19$$
:::

::: 정리 나머지정리
다항식 $f(x)$를 일차식 $x - a$로 나누었을 때의 나머지는 $f(a)$이다.
:::

::: 증명
$f(x)$를 $x-a$로 나눈 몫을 $Q(x)$, 나머지를 $R$라 하면
$f(x) = (x-a)Q(x) + R$ 이다. 양변에 $x = a$를 대입하면 $f(a) = R$ 이다.
:::

::: 주의
$\frac{1}{x}$처럼 분모에 문자가 있는 식은 다항식이 아니다.
:::

\columns{2}

::: 문제 [3점]
$(2x+1)^2$을 전개한 식은?

① $4x^2+1$ ② $4x^2+2x+1$ ③ $4x^2+4x+1$ ④ $2x^2+4x+1$ ⑤ $4x^2+4x+2$

[정답] ③
[해설]
$(2x+1)^2 = 4x^2 + 2 \cdot 2x \cdot 1 + 1 = 4x^2 + 4x + 1$
:::

::: 문제
다항식 $f(x) = x^3 - 2x + k$를 $x - 1$로 나눈 나머지가 $3$일 때, 상수 $k$의 값은?

① $1$ ② $2$ ③ $3$ ④ $4$ ⑤ $5$

[정답] ④
[해설]
나머지정리에 의해 $f(1) = 1 - 2 + k = 3$ 이므로 $k = 4$
:::

::: 문제 [4점]
$x = \sqrt{3} + 1$일 때, $x^2 - 2x$의 값을 구하시오.

[정답] $2$
[해설]
$x - 1 = \sqrt{3}$의 양변을 제곱하면 $x^2 - 2x + 1 = 3$
$$\therefore x^2 - 2x = 2$$
:::

::: 문제 서술형
이차방정식 $x^2 - 5x + 6 = 0$의 두 근을 $\alpha$, $\beta$라 할 때,
$\dfrac{1}{\alpha} + \dfrac{1}{\beta}$의 값을 구하는 과정을 서술하시오.

\vspace{25mm}

[정답] $\dfrac{5}{6}$
[해설]
근과 계수의 관계에 의해 $\alpha + \beta = 5$, $\alpha\beta = 6$
$$\frac{1}{\alpha} + \frac{1}{\beta} = \frac{\alpha + \beta}{\alpha\beta} = \frac{5}{6}$$
:::

# Ⅱ. 방정식과 부등식

## 1. 복소수

::: 정의 허수단위
제곱하여 $-1$이 되는 수를 $i$로 나타내고, 이것을 **허수단위**라 한다.
$$i^2 = -1, \quad i = \sqrt{-1}$$
:::

연립방정식과 행렬, 그리고 조건에 따라 달라지는 함수도 수식으로 쓸 수 있다.

$$\begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} 5 \\ 6 \end{pmatrix}$$

$$|x| = \begin{cases} x & (x \ge 0) \\ -x & (x < 0) \end{cases}$$

::: 문제
$(1+i)^2$의 값은?

① $-2$ ② $-2i$ ③ $0$ ④ $2i$ ⑤ $2$

[정답] ④
[해설]
$(1+i)^2 = 1 + 2i + i^2 = 2i$
:::

::: 문제
$\displaystyle\lim_{x \to 0} \frac{\sin 3x}{x}$의 값은?

① $0$ ② $1$ ③ $\frac{1}{3}$ ④ $3$ ⑤ $\infty$

[정답] ④
:::

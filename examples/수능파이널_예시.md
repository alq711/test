# 09 수직선 위의 운동

\머리말 공통 9번

## 핵심 개념

### 1 위치·속도·가속도의 관계

$$v(t) = x'(t), \qquad a(t) = v'(t) = x''(t)$$

$$x(t) = x(0) + \int_0^t v(s)\,ds$$

- **위치가 같아진다** → 두 점의 위치식(적분한 식)을 같게 놓는다.
- **속도가 같아진다** → 위치식을 미분한 식을 같게 놓는다. 그 순간의 가속도는 한 번 더 미분해서 대입한다.

### 2 운동 방향과 움직인 거리

$$\text{위치의 변화량} = \int_a^b v(t)\,dt, \qquad \text{움직인 거리} = \int_a^b |v(t)|\,dt$$

- 〈보기〉형(26학년도 11번 세 문항): ㄱ은 대입, ㄴ은 $v = 0$과 부호 변화, ㄷ은 움직인 거리 $\int |v|\,dt$로 구성되는 경우가 대부분이다.

::: 주의
"원점으로부터의 위치"와 "움직인 거리"를 섞지 않는다. 구간 안에서 $v$의 부호가 바뀌면 거리는 구간을 나누어 계산한다.
:::

## 최근 기출 | 공통 9번

::: 문제 2027학년도 9월 모의평가 9번
수직선 위를 움직이는 두 점 P, Q가 있다. 시각이 $t\ (t \ge 0)$일 때 두 점 P, Q의 위치가 각각
$$x_1 = 4t^3 - t^2 - 11t, \quad x_2 = 2t^2 + 7t + 3$$
이다. 두 점 P, Q의 속도가 같아지는 순간 두 점 P, Q의 가속도를 각각 $p$, $q$라 할 때, $p - q$의 값은? [4점]

① $30$ ② $33$ ③ $36$ ④ $39$ ⑤ $42$

[정답] ①
[해설]
$v_1 = 12t^2 - 2t - 11$, $v_2 = 4t + 7$. $2t^2 - t - 3 = 0 \to t = \frac{3}{2}$.
$p = 24t - 2 = 34$, $q = 4 \to p - q = 30$.
:::

::: 문제 2027학년도 6월 모의평가 9번
시각 $t = 0$일 때 동시에 원점을 출발하여 수직선 위를 움직이는 두 점 P, Q가 있다. 시각이 $t\ (t \ge 0)$일 때 두 점 P, Q의 속도가 각각
$$v_1(t) = t^2 - t, \quad v_2(t) = t$$
이다. 출발한 후 시각 $t = k$에서 두 점 P, Q의 위치가 같아질 때, 양수 $k$의 값은? [4점]

① $1$ ② $2$ ③ $3$ ④ $4$ ⑤ $5$

[정답] ③
[해설]
$x_{\mathrm{P}} = \frac{t^3}{3} - \frac{t^2}{2}$, $x_{\mathrm{Q}} = \frac{t^2}{2}$. $\frac{k^3}{3} - k^2 = 0 \to k = 3$.
:::

# 10 지수·로그함수 그래프

\머리말 공통 10번

## 핵심 개념

### 1 지수함수·로그함수 그래프의 기본

- $y = a^{x-m} + n$: 점근선 $y = n$, 지나는 점 $(m,\ 1 + n)$
- $y = \log_a (x - m) + n$: 점근선 $x = m$, 지나는 점 $(m + 1,\ n)$
- $y = \log_a (-x + 3)$처럼 $x$ 앞에 $-$가 붙으면 $y$축 대칭이 섞여 있다.

### 2 선분의 길이를 지수·로그로 바꾸기

$$pa^{x_1} = qa^{x_2} = k \;\Rightarrow\; x_2 - x_1 = \log_a \frac{p}{q}$$

### 3 도형 조건을 식으로

- **정삼각형**: 밑변의 중점에서 높이 $= \frac{\sqrt{3}}{2} \times$ 한 변. 대칭축이 있으면 꼭짓점은 대칭축 위에 있다.
- **이등변삼각형** $\overline{\mathrm{AB}} = \overline{\mathrm{BC}}$: 중점 조건으로 바꾸면 좌표 한 개가 바로 결정된다.
- **넓이**: 한 변이 축에 평행하도록 밑변을 잡는다.

::: 주의
답이 $2^{\frac{13}{6}}$처럼 지수 꼴이면 마지막에 $a^x = 2^{\cdots}$를 정리할 때 지수법칙 실수가 잦다.
:::

## 최근 기출 | 공통 10번

::: 문제 2027학년도 9월 모의평가 10번
상수 $a\ (a > 1)$에 대하여 직선 $y = 7$이 두 곡선 $y = 16a^x$, $y = \frac{1}{4}a^x$과 만나는 점을 각각 A, B라 하자. $\overline{\mathrm{AB}} = 4$일 때, $a$의 값은? [4점]

① $\sqrt{2}$ ② $2$ ③ $2\sqrt{2}$ ④ $4$ ⑤ $4\sqrt{2}$

[정답] ③
[해설]
$x_{\mathrm{A}} = \log_a \frac{7}{16}$, $x_{\mathrm{B}} = \log_a 28$.
$$\overline{\mathrm{AB}} = \log_a 28 - \log_a \frac{7}{16} = \log_a 64 = 4 \;\Rightarrow\; a = 2\sqrt{2}$$
:::

::: 문제 2027학년도 6월 모의평가 10번
두 양수 $a$, $b$가
$$\log_9 a + \log_3 b = 2, \quad \log_3 a = 8\log_9 b$$
를 만족시킬 때, $\dfrac{a}{b}$의 값은? [4점]

① $1$ ② $3$ ③ $9$ ④ $27$ ⑤ $81$

[정답] ③
[해설]
$A = \log_3 a$, $B = \log_3 b$: $\frac{A}{2} + B = 2$, $A = 4B \to B = \frac{2}{3}$, $A = \frac{8}{3}$.
$\frac{a}{b} = 3^{A - B} = 3^2 = 9$.
:::

# 01 포물선

## 1. 포물선의 방정식

::: 정의 포물선
평면 위의 한 점 F와 F를 지나지 않는 한 직선 $l$이 있을 때, 점 F와 직선 $l$에 이르는 거리가 같은 점들의 집합을 **포물선**이라 한다. 점 F를 **초점**, 직선 $l$을 **준선**이라 한다.
:::

::: 정리 포물선의 방정식
초점이 $\mathrm{F}(p,\,0)$이고 준선이 $x=-p$인 포물선의 방정식은
$$y^2 = 4px \quad (p \ne 0)$$
초점이 $\mathrm{F}(0,\,p)$이고 준선이 $y=-p$인 포물선의 방정식은
$$x^2 = 4py \quad (p \ne 0)$$
:::

::: 증명
포물선 위의 점을 $\mathrm{P}(x,\,y)$라 하면 $\overline{\mathrm{PF}}$는 점 P와 준선 사이의 거리와 같으므로
$$\sqrt{(x-p)^2 + y^2} = |x + p|$$
양변을 제곱하여 정리하면 $y^2 = 4px$이다.
:::

### 평행이동한 포물선

::: 공식
$$(y-n)^2 = 4p(x-m) \;\Rightarrow\; \text{꼭짓점 } (m,\,n),\ \text{초점 } (m+p,\,n),\ \text{준선 } x = m - p$$
:::

- **정의를 먼저 쓴다**: 포물선 위의 점 P에 대하여 $\overline{\mathrm{PF}}$ = (P에서 준선까지의 거리)
- $p$의 부호로 열린 방향을 확인한다.

::: 예제 준선 구하기
포물선 $y^2 = 8(x+1)$의 초점과 준선을 구하시오.
[풀이]
$4p = 8$에서 $p = 2$. 꼭짓점이 $(-1,\,0)$이므로 초점은 $(1,\,0)$, 준선은 $x = -3$이다.
:::

::: 주의
$y^2 = -12(x-1)$처럼 $p < 0$이면 초점은 꼭짓점의 왼쪽, 준선은 오른쪽에 있다.
:::

## 확인 문제

::: 문제 2024학년도 6월 모의평가 23번
포물선 $y^2=-12(x-1)$의 준선을 $x=k$라 할 때, 상수 $k$의 값은? [2점]

① $4$ ② $7$ ③ $10$ ④ $13$ ⑤ $16$

[정답] ①
[해설]
$4p = -12$에서 $p = -3$. 꼭짓점이 $(1,\,0)$이므로 준선은 $x = 1 - (-3) = 4$.
:::

::: 문제 2023학년도 수능 24번
초점이 $\mathrm{F}\left(\dfrac{1}{3},\,0\right)$이고 준선이 $x=-\dfrac{1}{3}$인 포물선이 점 $(a,\,2)$를 지날 때, $a$의 값은? [3점]

① $1$ ② $2$ ③ $3$ ④ $4$ ⑤ $5$

[정답] ③
[해설]
포물선은 $y^2 = \dfrac{4}{3}x$. 점 $(a,\,2)$를 대입하면 $4 = \dfrac{4}{3}a$이므로 $a = 3$.
:::

# 02 타원

## 1. 타원의 방정식

::: 정의 타원
평면 위의 서로 다른 두 점 F, F$'$에서의 거리의 합이 일정한 점들의 집합을 **타원**이라 한다. 두 점 F, F$'$을 **초점**이라 한다.
:::

::: 정리 타원의 방정식
두 초점 $\mathrm{F}(c,\,0)$, $\mathrm{F'}(-c,\,0)$에서의 거리의 합이 $2a$인 타원의 방정식은
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (a > c > 0,\ b^2 = a^2 - c^2)$$
:::

- 장축의 길이 $2a$, 단축의 길이 $2b$
- 초점이 $y$축 위에 있으면 $b > a$이고 $c^2 = b^2 - a^2$

::: 개념확인
타원 $\dfrac{x^2}{25} + \dfrac{y^2}{9} = 1$의 두 초점 사이의 거리는? (답: $8$)
:::

## 확인 문제

::: 문제 2025학년도 9월 모의평가 24번
타원 $\dfrac{x^2}{4^2}+\dfrac{y^2}{b^2}=1$의 두 초점 사이의 거리가 $6$일 때, $b^2$의 값은? (단, $0<b<4$) [3점]

① $4$ ② $5$ ③ $6$ ④ $7$ ⑤ $8$

[정답] ④
[해설]
$2c = 6$에서 $c = 3$. $b^2 = 4^2 - 3^2 = 7$.
:::
